# Personal Introduction Page

## 📌 Project Description

A simple single-page personal introduction website created as part of the Veda Technology Day 2 Task.

The website contains my introduction, education, skills, hobbies, and contact information.

## 🎯 Objective

- Practice basic HTML5 elements
- Practice CSS3 selectors and styling
- Learn spacing, colors, and simple page layout
- Create a single-page personal introduction website

## ✨ Features

- Home section
- About Me section
- Skills section
- Hobbies section
- Contact section
- Same-page navigation using anchor links
- Clean and simple layout

## 🛠️ Technologies Used

- HTML5
- CSS3
